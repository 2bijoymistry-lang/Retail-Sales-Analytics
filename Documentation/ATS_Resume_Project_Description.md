## Option A — Full Version (4 bullets)

**Retail Sales Analytics Dashboard | Power BI, DAX, Power Query, SQL, Python**

- Designed and built an end-to-end Power BI business intelligence solution, consolidating customer, order, product, and transaction data (500+ customers, 5,000+ orders) into a governed star-schema data model with four dimension tables and one fact table.
- Developed a centralized DAX measure library (Total Sales, Total Orders, Total Customers, Quantity Sold, Average Order Value) to replace manual spreadsheet reporting with a single, consistent source of truth across all stakeholder teams.
- Engineered ETL transformations in Power Query — standardizing data types, deduplicating keys, and validating relationship integrity — to ensure model accuracy and refresh reliability.
- Designed an executive dashboard using F-pattern UX principles with cross-filtered, slicer-driven interactivity across Year, Quarter, Category, and Payment Mode, enabling self-service analysis for CEO, Sales, Marketing, Finance, and Operations stakeholders.
